# Сайт-резюме Дмитрия Нечаева

Первый статический набросок персонального сайта Python-разработчика.

## Локальный запуск

Откройте `index.html` в браузере или запустите простой HTTP-сервер:

```powershell
python -m http.server 8000
```

После этого сайт будет доступен по адресу `http://localhost:8000`.
